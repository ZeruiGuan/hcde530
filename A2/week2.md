# Week 2 — Competency Claim

## C2 — Code Literacy and Documentation

I frame code literacy as sense-making rather than memorizing syntax. In 'demo_word_count.py', I demonstrate this by writing comments like “Open the CSV file so the script can read all survey responses” and “Save each row so we can process all responses later,” which explicitly connect each step to its purpose in the overall workflow. I also included a docstring for 'count_words(response)' and shortened long responses for readability, showing that I am making both the code and its output interpretable for a human reader, not just executable.
